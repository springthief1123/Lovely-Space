# 要件

2026-10-03 に Yuya が示した要件と、それぞれの対応状況です。状況の詳細と残りのタスクは [roadmap.md](roadmap.md) と GitHub の issue を参照してください。

## 目的

2ショットチャット「ラブルーム」（https://2shot.chat.shalove.net/ ）専用のブラウザアプリ。ラブルームの Web サイトにある機能を網羅しつつ、古めかしい本家サイトをそのまま表示せず、モダンなチャットアプリ風の独自 UI にする。

## 制約

- **本家の利用規約**: 「通常のブラウザ利用とは異なるアクセスを繰り返すような個人によるツールアクセス」を禁止している。アプリはすべての通信の間隔を制限し、取得結果を機能間で共有して、人がブラウザで操作する程度の頻度に抑える。本家の情報の無断複製・転載も禁止されているため、取得したデータを端末の外へ送ったり共有したりする機能は作らない。
- **ロボット確認**: 部屋作成では毎回、入室では前回の利用から間が空いたときなどに、Cloudflare Turnstile（失敗時は hCaptcha）が入る。回避はせず、利用者が WebView で通す。
- **配布**: 成人向けかつ第三者サイトのクライアントのため Google Play には出さず、署名付き APK を直接配布する想定（#50）。
- **地域**: 本家は EU / EEA の居住者へのサービス提供を禁止している。
