# Quiet Rose 実装

2026-10-06の再設計案に基づき、見つける・レーダー・保存・マイルームへ再構成。

- 暖かいニュートラル、ローズ、落ち着いたインク色。Glassはヘッダー、下部ナビ、作成ボタン。
- 名前と募集文を横断する検索を部屋発見に統合。入力では通信せず、詳細な条件をシートに収納。
- 部屋の全文、保存、追跡、非表示、入室前確認を詳細シートに集約。スワイプ以外の操作と非表示のUndoも提供。
- 保存には部屋と条件の棚。設定と部屋作成、プロフィール・募集文の管理はマイルーム。
- 検索条件の新しい共通検索欄はDB 3→4で追加。既存の設定・保存・非表示を保持。

## 今回動くレーダー

端末内の手動巡回。保存した条件を複数選択し、計画ごとに1ページを取得、次の巡回では次ページへ進む。同じジャンル・ページのリクエストはまとめる。各計画の巡回ページは開始時に固定し、他の計画の通信で進めすぎない。部屋追跡は先頭ページと発見画面で取得したページを利用。通信は既存の共有ShaloveClientと間隔制限を通す。

キャッシュからの再表示は新しい観測に数えない。ページごとの初回確認では基準を作り、以降の新しい一致を履歴に保存。同じ計画の別ページへの移動で重複して新規一致を通知しない。計画条件が変わったら新たな基準を作る。履歴は端末内100件、計画と追跡先は既存LocalStateへ保存。基準と巡回ページは再起動時にリセット。

追跡はhost・room ID・ジャンルと確認可能な名前・性別・年齢の照合。名前が隠れた満室は本人確認できないため「プロフィール未確認」。プロフィールの矛盾はID再利用の可能性として停止。未取得ページや通信失敗から不在・オフラインを判定しない。IDを確認した時刻とプロフィールを照合した時刻を別々に保持。画面の表示は現在の在室を保証しない。非表示の一致は巡回結果から除外。
