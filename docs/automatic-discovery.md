# 自動取得・入室・公開閲覧（2026-10-07）

- 画面の見出しは「見つける」「レーダー」「保存」「マイルーム」「入室」「部屋を作成」。英語の飾り見出し・キャッチコピーを撤去する。
- 「見つける」は初回から自動取得。最新ページを優先し、残りのページも取得する。「続きを読み込む」は廃止する。検索条件は取得済みページに即時適用する。
- レーダーは有効な計画・候補条件・追跡先を自動確認する。新着ページの優先取得は残りページの巡回位置をリセットしない。一致した部屋はレーダー上に直接表示する。
- 自動取得は各画面がRESUMEDの間だけ実行する。タブ離脱・入室・バックグラウンド移行で取り消し、戻ると再開する。スイッチで一時停止できる。バックグラウンド監視・OS通知は含まない。
- 本家への最小通信間隔3秒と一覧キャッシュ20秒を保持する。自動取得はキャッシュを強制破棄しない。最新ページの優先確認は20秒を目安とするが、通信待ち・他ジャンルの取得・回線状況で遅くなる。秒単位の即時通知や他利用者より先に入室できることは保証しない。
- 一覧はページ単位で更新する。同じ部屋のページ移動は新しい観測を優先し、全ページ数が減った場合は範囲外の情報を落とす。未更新のページは取得時の情報として保持する。未観測を退室・削除と断定しない。
- 部屋カードのタップで入室フォーム、公開満室なら公開閲覧へ直接進む。詳細はメニューに残す。独自の入室確認ダイアログは撤去する。履歴・ID再利用の照合、プロフィール入力、サイトが要求する認証は保持する。自動入室は行わない。
- 公開ルームはHTTPで公開ログを取得し、アプリのチャット表示に描画する。WebView・サイトのヘッダー・広告・発言フォームを表示しない。閲覧用なので入室・発言・退室の送信は行わない。20秒間隔で再取得し、閲覧できなくなった場合は古いログを消して自動取得を停止する。

## 検証

ページ置換・重複・状態変化・総ページ減少・新着優先と巡回位置・失敗再試行・通信取消・公開ログ解析・同じ発言の重複・非公開変更時の表示停止に回帰テストを追加した。

この作業環境からGradle配布先と本家の実ページを取得できないため、Androidビルド・core/appテスト・LintはPRのGitHub Actionsで確認する必要がある。公開閲覧の実HTMLとの適合、チャHでの新着確認、カードタップからの入室、Light/Darkの視認性は実機検証が必要。
